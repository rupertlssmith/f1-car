# Front-wheel fix variants

Test cars generated by `tools/rb14/variants.py` (round 12): each tries a fix for
the front wheels' judder / wobble in hard corners (and the front wing shaking
with them). Everything else is **Baseline**. In the game they are in the RB14's
configuration list as *Front Fix N · ...*, safest first; the later ones go over
an offline limit on purpose and may break at spawn. Note for each: does it
spawn cleanly, and how the front feels in a hard corner.

Offline checks: stiffness = highest omega*dt (target <= 1.65), damped = with
damping (<= 1.85), corner = wheel-corner modes with damping (<= 1.78; round 10
was 1.78 and fine, round 11 1.83 and broke), tyres = stiffness per kg vs the F4's (<= 1).
