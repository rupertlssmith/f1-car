# Steering-centring variants

Test cars generated by `tools/rb14/variants.py` (round 13): each tries a fix for
the steering not quite re-centring after hard turning. Everything else is
**Baseline** (round 12's Front Fix 4). In the game they are in the RB14's
configuration list as *Steering Fix N · ...*. Note for each: does it spawn
cleanly, does the steering come back to centre after a few hard corners, and
any change in the front-wheel wobble. Round 12's results (Front Fix 1-5) are in
`plans/front-fixes.md`.

Offline checks: stiffness = highest omega*dt (target <= 1.67), damped = with
damping (<= 1.85), corner = wheel-corner modes with damping (<= 1.82; round 10
was 1.78 and fine, round 11 1.83 and broke), tyres = stiffness per kg vs the F4's (<= 1).
