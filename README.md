# F1 Car for BeamNG.drive

A Formula 1-style open-wheel race car mod for [BeamNG.drive](https://www.beamng.com/).

> **Status:** early development — work in progress.

## Installation

1. Download or clone this repository.
2. Zip the mod contents (so that folders like `vehicles/` sit at the root of the zip).
3. Place the zip in your BeamNG.drive mods folder:
   - Windows: `%LocalAppData%\BeamNG.drive\<version>\mods\`
4. Launch the game and enable the mod in the Mod Manager if needed.
5. Find the car in the vehicle selector.
